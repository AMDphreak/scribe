= Scribe documentation
:description: User guide for Scribe — edit and publish static-site content without living on the command line.
:keywords: Scribe, AsciiDoc, Markdown, GitHub, GitLab, static site

Scribe is a desktop app for editing link:https://asciidoctor.org[AsciiDoc] and Markdown in Git-backed static site repositories.
It targets people who maintain sites built with Astro, Hugo, Jekyll, Eleventy, and similar generators, but who do not want to manage Git or OAuth details by hand for day-to-day edits.

== What you can do

* Open a **GitHub** or **GitLab** repository by URL, work in a focused editor, and **Publish** (commit and push) from the app.
* Stay out of the terminal for normal authoring; Scribe can install or use **Git** and **GitHub CLI** where needed (see Help → Set up tools on Windows).
* Use **profiles** (SDL) for host-specific auth and API endpoints—see xref:oauth-setup.adoc[OAuth and API access] when you need your own OAuth application.

== First steps

. Install Scribe from the link:https://github.com/AMDphreak/scribe/releases[Releases] page (or build from source).
. Open the app and paste your site’s repository URL, then choose **Open Site** to clone and open the project.
. Complete browser login when prompted so Scribe can talk to the host API for publish operations.
. Edit pages; use **Publish** when you are ready to push commits to the default branch (workflow details depend on your repo).
