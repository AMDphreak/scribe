= Syndrome Documentation

Syndrome is a desktop app for editing Markdown and AsciiDoc content in GitHub-hosted static site repositories.

== Getting started

* Download or build the app from the link:https://github.com/AMDphreak/syndrome[repository].
* Use Help → Set up tools to install GitHub CLI and Git (Windows: winget), then log in.
* Paste a GitHub repo URL and click Open repo to clone and edit content.
