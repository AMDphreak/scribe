= 2026-04-12: Antora docs — npm antora-dark-theme + layered supplementals

== Overview

Documentation builds use the Antora default UI from GitLab plus **supplemental UI layers**: `antora-dark-theme` installed from npm, then project files under `site/src`, as described in the theme’s “Method 3” setup.

== Changes

* **Playbook**: `antora-playbook.yml` uses the default `antora-ui-default` bundle URL and `supplemental_files` listing `./node_modules/antora-dark-theme/supplemental-ui` before `./site/src` so later layers can override.
* **Dependencies**: `antora-dark-theme` is a root devDependency so the version is pinned in `package.json` / the lockfile and CI runs `pnpm install` before Antora.
